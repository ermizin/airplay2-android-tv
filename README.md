# AirPlay 2 на Android TV-приставке

Настоящий приёмник AirPlay 2 с мультирумом на приставке с Android, которая остаётся обычной Android-приставкой. Плюс экран «Сейчас играет» на телевизоре с построчным текстом песни.

Проверено на одной приставке: **Tox3, Amlogic, Android 11 (32-битный), ядро 5.4, root через Magisk**. На других моделях звуковые устройства и настройки будут отличаться.

## Что умеет

- Приёмник AirPlay 2: появляется на iPhone и Mac рядом с HomePod, играет в группе с ними.
- Звук напрямую в HDMI, без участия звуковой системы Android.
- Приставка спит как обычно и выключает телевизор по HDMI-CEC, а приёмник при этом остаётся в сети. Когда начинается музыка, приставка просыпается и включает телевизор.
- Экран с обложкой, названием, полоской времени и текущим фоном из цветов обложки.
- Построчный текст песни с синхронизацией по позиции, которую присылает плеер. Перемотка и пауза учитываются.

## Как устроено

```
iPhone / Mac ── AirPlay 2 ──> shairport-sync + nqptp (Debian 12 в chroot)
                                 │                    │
                                 │ метаданные          │ ALSA hw:0,4 (S/PDIF → HDMI)
                                 ▼                    ▼
                            nowplaying.py          телевизор
                                 │   ▲
              страница, текст,   │   └── снятие звука с выхода (петля S/PDIF)
              позиция, уровни    ▼
                       приложение WebView на весь экран
```

| Папка | Что внутри |
|---|---|
| `debian/` | сборка и запуск приёмника внутри Debian, сервис экрана `nowplaying.py` |
| `magisk/` | скрипты автозапуска для `/data/adb/service.d`, подключение окружения Debian |
| `android/` | исходники маленького приложения: WebView на весь экран |

## Требования

- Приставка с Android и root через Magisk, доступ по ADB.
- Debian 12 `armhf`. **Debian 13 не подойдёт для ядра 5.4:** в нём ALSA использует 64-битное время, и звуковые устройства не открываются.
- Для сборки приложения: JDK 17, Android build-tools и `android.jar` (платформа 30).

## Установка

1. Распаковать образ Debian 12 `armhf` в `/data/local/debian12`. На приставке прописать в нём `resolv.conf`, `hosts` и `APT::Sandbox::User "root"`.
2. Скопировать `magisk/debian-mount.sh` в `/data/local/` и запустить от root.
3. Скопировать файлы `debian/` в `/root/` внутри Debian, `shairport-sync.conf` в `/etc/`. Выполнить внутри Debian `/root/build.sh`.
4. Там же поставить зависимости экрана:
   ```bash
   apt-get install -y --no-install-recommends python3-numpy fonts-inter
   ```
5. Скопировать `magisk/airplay2.sh` и `magisk/airplay2-wake.sh` в `/data/adb/service.d/`, сделать их исполняемыми.
6. Собрать и поставить приложение:
   ```bash
   ANDROID_JAR=/path/to/android.jar BUILD_TOOLS=/path/to/build-tools ./android/build-apk.sh
   adb install -r android/build/nowplaying.apk
   ```
7. Перезагрузить приставку.

## Настройка

| Что | Где |
|---|---|
| Имя приёмника | `NAME` в `debian/start-airplay2.sh` и `debian/restart-shairport.sh` |
| Синхронность с другими колонками | `audio_backend_latency_offset_in_seconds` в `shairport-sync.conf` |
| Задержка текста относительно звука | число в секундах в файле `/root/np-lyrics-delay` внутри Debian, применяется сразу |

Порт приёмника `7010`, потому что `7000` может быть занят другим приёмником AirPlay на приставке.

## Ограничения

- Устройство вывода `hw:0,4` и петля `Audio spdifin source` относятся к звуковой схеме Amlogic.
- Текст есть не у всех песен. Его тайминг неточен в пределах нескольких десятых секунды.
- Глубокий сон приставки заблокирован, поэтому в спящем режиме она потребляет больше обычного.
- После перезапуска приёмника устройства Apple могут обновлять список AirPlay с задержкой.

## Что уходит в сеть

Для поиска текста приставка отправляет название песни, исполнителя и альбом в [LRCLIB](https://lrclib.net). Найденные тексты сохраняются на приставке.

## Безопасность

Для установки нужны root и ADB по сети. Когда всё настроено, закройте их: на многих прошивках ADB открыт без подтверждения, и подключиться может любое устройство в вашей сети.
